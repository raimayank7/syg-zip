Where Caribou County is

The ZIP codes of Caribou County are found in the south-east of Idaho. From the northernmost code to the southernmost is about 33 miles, and from east to west about 30 miles. The two codes farthest apart are 83241 (Grace) and 83285 (Wayan), about 41 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Bannock County (34 miles), Bear Lake County (37 miles), Franklin County (43 miles) and Lincoln County, Wyoming (44 miles).

The first three digits

Every ZIP code of Caribou County starts with 832. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 832 is shared with 9 other counties, such as Bannock County, Bear Lake County and Bingham County, and has 57 codes in all.

How much ground the codes cover

The Census Bureau draws an area for 4 of the 5 codes. Together they come to about 1,406 square miles of land (3,642 sq km). The largest is 83276 (Soda Springs) with 694 square miles, and the smallest is 83241 (Grace) with 197. The middle-sized code here covers 258 square miles; the middle value for all of Idaho is 111. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Caribou County; a code can reach across its border. One code has no mapped area: 83230 (Conda). Codes like these are normally for post office boxes or one large building.

By number of ZIP codes, Caribou County ranks 23rd among the 44 counties and county-level areas of Idaho (equal counts share a rank), with 5 of the 320 codes in the state list.

Writing an address in Caribou County

The name of the county is not written in a United States address. The last line is the postal city, the letters ID and the ZIP code:

  • Bancroft, ID 83217
  • Conda, ID 83230
  • Grace, ID 83241

Bancroft is also the name of a place with a ZIP code in 5 other states, which is why the two state letters and the code matter more than the town name.
