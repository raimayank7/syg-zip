Where Lewis County is

On the map, the ZIP codes of Lewis County fall in the west of Idaho. From the northernmost code to the southernmost is about 8.1 miles, and from east to west about 28 miles. The two codes farthest apart are 83536 (Kamiah) and 83555 (Winchester), about 28 miles from each other in a straight line. Measured between the middle points of their codes, the closest neighbours are Nez Perce County (18 miles), Clearwater County (22 miles), Asotin County, Washington (32 miles) and Idaho County (34 miles).

The first three digits

Every ZIP code of Lewis County starts with 835. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 835 is shared with 4 other counties, such as Clearwater County, Idaho County and Latah County, and has 28 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 764 square miles of land (1,980 sq km). The largest is 83523 (Craigmont) with 221 square miles, and the smallest is 83548 (Reubens) with 25.4. The middle-sized code here covers 182 square miles; the middle value for all of Idaho is 111. These areas follow ZIP code delivery routes, so their total is not the official size of Lewis County; a code can reach across its border.

By number of ZIP codes, Lewis County ranks 23rd among the 44 counties and county-level areas of Idaho (equal counts share a rank), with 5 of the 320 codes in the state list.

Writing an address in Lewis County

The name of the county is not written in a United States address. The last line is the postal city, the letters ID and the ZIP code:
