Where Boise County is

Going by the map points of its ZIP codes, Boise County is in the south-west of Idaho. From the northernmost code to the southernmost is about 32 miles, and from east to west about 45 miles. The two codes farthest apart are 83637 (Lowman) and 83646 (Meridian), about 55 miles from each other in a straight line. Measured between the middle points of their codes, the closest neighbours are Gem County (23 miles), Ada County (31 miles), Canyon County (43 miles) and Payette County (46 miles).

The first three digits

Every ZIP code of Boise County starts with 836. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 836 is shared with 10 other counties, such as Ada County, Adams County and Canyon County, and has 58 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 1,154 square miles of land (2,989 sq km). The largest is 83637 (Lowman) with 455 square miles, and the smallest is 83666 (Placerville) with 10.2. The middle-sized code here covers 168 square miles; the middle value for all of Idaho is 111. These areas follow ZIP code delivery routes, so their total is not the official size of Boise County; a code can reach across its border.

By number of ZIP codes, Boise County ranks 16th among the 44 counties and county-level areas of Idaho (equal counts share a rank), with 7 of the 320 codes in the state list.

Writing an address in Boise County

The name of the county is not written in a United States address. The last line is the postal city, the letters ID and the ZIP code:

  • Banks, ID 83602
  • Garden Valley, ID 83622
  • Horseshoe Bend, ID 83629

Banks is also the name of a place with a ZIP code in 3 other states, which is why the two state letters and the code matter more than the town name. Meridian shares a name with a place in another part of Idaho; there the ZIP code tells the two apart.
