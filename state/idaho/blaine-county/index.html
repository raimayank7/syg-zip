Where Blaine County is

Going by the map points of its ZIP codes, Blaine County is in the south of Idaho. From the northernmost code to the southernmost is about 28 miles, and from east to west about 30 miles. The two codes farthest apart are 83320 (Carey) and 83340 (Ketchum), about 40 miles from each other in a straight line. Measured between the middle points of their codes, the closest neighbours are Camas County (32 miles), Lincoln County (36 miles), Butte County (51 miles) and Gooding County (52 miles).

The first three digits

Every ZIP code of Blaine County starts with 833. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 833 is shared with 7 other counties, such as Camas County, Cassia County and Gooding County, and has 39 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 1,790 square miles of land (4,637 sq km). The largest is 83340 (Ketchum) with 558 square miles, and the smallest is 83354 (Sun Valley) with 0.02. The middle-sized code here covers 258 square miles; the middle value for all of Idaho is 111. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Blaine County; a code can reach across its border.

By number of ZIP codes, Blaine County ranks 16th among the 44 counties and county-level areas of Idaho (equal counts share a rank), with 7 of the 320 codes in the state list.

Writing an address in Blaine County

The name of the county is not written in a United States address. The last line is the postal city, the letters ID and the ZIP code:

  • Sun Valley, ID 83353 (one of 2 codes for Sun Valley; the street decides which)
  • Bellevue, ID 83313
  • Carey, ID 83320

Sun Valley is also the name of a place with a ZIP code in 3 other states, which is why the two state letters and the code matter more than the town name.
