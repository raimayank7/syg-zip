Where Elmore County is

Going by the map points of its ZIP codes, Elmore County is in the south-west of Idaho. From the northernmost code to the southernmost is about 62 miles, and from east to west about 61 miles. The two codes farthest apart are 83633 (King Hill) and 83648 (Mountain Home Afb), about 83 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Camas County (36 miles), Ada County (40 miles), Owyhee County (47 miles) and Gooding County (47 miles).

The first three digits

Every ZIP code of Elmore County starts with 836. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 836 is shared with 10 other counties, such as Ada County, Adams County and Boise County, and has 58 codes in all.

How much ground the codes cover

The Census Bureau draws an area for 5 of the 6 codes. Together they come to about 1,997 square miles of land (5,171 sq km). The largest is 83647 (Mountain Home) with 1,505 square miles, and the smallest is 83648 (Mountain Home Afb) with 10.0. The middle-sized code here covers 149 square miles; the middle value for all of Idaho is 111. These areas follow ZIP code delivery routes, so their total is not the official size of Elmore County; a code can reach across its border. One code has no mapped area: 83601 (Atlanta). Codes like these are normally for post office boxes or one large building.

By number of ZIP codes, Elmore County ranks 18th among the 44 counties and county-level areas of Idaho (equal counts share a rank), with 6 of the 320 codes in the state list.

Writing an address in Elmore County

The name of the county is not written in a United States address. The last line is the postal city, the letters ID and the ZIP code:

  • Atlanta, ID 83601
  • Glenns Ferry, ID 83623
  • Hammett, ID 83627

Atlanta is also the name of a place with a ZIP code in 10 other states, which is why the two state letters and the code matter more than the town name.
