Where Ada County is

Going by the map points of its ZIP codes, Ada County is in the south-west of Idaho. From the northernmost code to the southernmost is about 19 miles, and from east to west about 26 miles. The two codes farthest apart are 83669 (Star) and 83716 (Boise), about 29 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Canyon County (24 miles), Boise County (31 miles), Owyhee County (32 miles) and Gem County (33 miles).

The first three digits

The codes of Ada County begin with 837 (29 codes) and 836 (5 codes). The first three digits of a ZIP code name the mail sorting area it belongs to. No other county-level area in this list uses 837, so those three digits alone point to Ada County.

How much ground the codes cover

The Census Bureau draws an area for 16 of the 34 codes. Together they come to about 1,559 square miles of land (4,039 sq km). The largest is 83716 (Boise) with 1,039 square miles, and the smallest is 83720 (Boise) with 0.01. The middle-sized code here covers 22.5 square miles; the middle value for all of Idaho is 111. Small code areas usually go with towns and suburbs where homes stand close together. These areas follow ZIP code delivery routes, so their total is not the official size of Ada County; a code can reach across its border. 18 codes have no mapped area: 83680 (Meridian), 83701 (Boise), 83707 (Boise), 83708 (Boise), 83711 (Boise) and 13 more. Codes like these are normally for post office boxes or one large building.

No other part of Idaho has more ZIP codes: Ada County holds 34 of the 320 in the state list, about 10.6%.

Writing an address in Ada County

The name of the county is not written in a United States address. The last line is the postal city, the letters ID and the ZIP code:

  • Boise, ID 83701 (one of 28 codes for Boise; the street decides which)
  • Meridian, ID 83642 (one of 2 codes for Meridian; the street decides which)
  • Eagle, ID 83616

Meridian shares a name with a place in another part of Idaho; there the ZIP code tells the two apart.
