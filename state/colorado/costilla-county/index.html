Where Costilla County is

On the map, the ZIP codes of Costilla County fall in the south of Colorado. From the northernmost code to the southernmost is about 30 miles, and from east to west about 14 miles. The two codes farthest apart are 81133 (Fort Garland) and 81138 (Jaroso), about 32 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Conejos County (29 miles), Alamosa County (32 miles), Huerfano County (39 miles) and Taos County, New Mexico (52 miles).

The first three digits

Every ZIP code of Costilla County starts with 811. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 811 is shared with 7 other counties, such as Alamosa County, Archuleta County and Conejos County, and has 32 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 1,058 square miles of land (2,741 sq km). The largest is 81152 (San Luis) with 481 square miles, and the smallest is 81126 (Chama) with 10.0. The middle-sized code here covers 146 square miles; the middle value for all of Colorado is 101. These areas follow ZIP code delivery routes, so their total is not the official size of Costilla County; a code can reach across its border.

By number of ZIP codes, Costilla County ranks 39th among the 64 counties and county-level areas of Colorado (equal counts share a rank), with 5 of the 645 codes in the state list.
