Where Saguache County is

Going by the map points of its ZIP codes, Saguache County is in the south of Colorado. From the northernmost code to the southernmost is about 46 miles, and from east to west about 40 miles. The two codes farthest apart are 81131 (Crestone) and 81248 (Sargents), about 50 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Rio Grande County (36 miles), Alamosa County (37 miles), Custer County (42 miles) and Chaffee County (42 miles).

The first three digits

The codes of Saguache County begin with 811 (5 codes) and 812 (1 code). The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 811 is shared with 7 other counties, such as Alamosa County, Archuleta County and Conejos County, and has 32 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 2,324 square miles of land (6,020 sq km). The largest is 81149 (Saguache) with 661 square miles, and the smallest is 81125 (Center) with 263. The middle-sized code here covers 373 square miles; the middle value for all of Colorado is 101. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Saguache County; a code can reach across its border.

By number of ZIP codes, Saguache County ranks 29th among the 64 counties and county-level areas of Colorado (equal counts share a rank), with 6 of the 645 codes in the state list.

Writing an address in Saguache County

The name of the county is not written in a United States address. The last line is the postal city, the letters CO and the ZIP code:

  • Center, CO 81125
  • Crestone, CO 81131
  • Moffat, CO 81143

Center is also the name of a place with a ZIP code in 5 other states, which is why the two state letters and the code matter more than the town name.
