Where Chaffee County is

Going by the map points of its ZIP codes, Chaffee County sits near the middle of Colorado. From the northernmost code to the southernmost is about 36 miles, and from east to west about 16 miles. The two codes farthest apart are 81201 (Salida) and 81228 (Granite), about 38 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Lake County (36 miles), Gunnison County (39 miles), Saguache County (42 miles) and Park County (42 miles).

The first three digits

Every ZIP code of Chaffee County starts with 812. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 812 is shared with 7 other counties, such as Custer County, Fremont County and Gunnison County, and has 32 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 1,064 square miles of land (2,757 sq km). The largest is 81211 (Buena Vista) with 478 square miles, and the smallest is 81227 (Monarch) with 0.4. The middle-sized code here covers 90.2 square miles; the middle value for all of Colorado is 101. These areas follow ZIP code delivery routes, so their total is not the official size of Chaffee County; a code can reach across its border.

By number of ZIP codes, Chaffee County ranks 29th among the 64 counties and county-level areas of Colorado (equal counts share a rank), with 6 of the 645 codes in the state list.

Writing an address in Chaffee County

The name of the county is not written in a United States address. The last line is the postal city, the letters CO and the ZIP code:

  • Buena Vista, CO 81211
  • Granite, CO 81228
  • Monarch, CO 81227

Buena Vista is also the name of a place with a ZIP code in 5 other states, which is why the two state letters and the code matter more than the town name.
