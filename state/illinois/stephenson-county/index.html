Where Stephenson County is

Going by the map points of its ZIP codes, Stephenson County is in the north of Illinois. From the northernmost code to the southernmost is about 18 miles, and from east to west about 26 miles. The two codes farthest apart are 61019 (Davis) and 61044 (Kent), about 28 miles from each other in a straight line. Measured between the middle points of their codes, the closest neighbours are Green County, Wisconsin (23 miles), Carroll County (25 miles), Winnebago County (28 miles) and Jo Daviess County (28 miles).

The first three digits

Every ZIP code of Stephenson County starts with 610. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 610 is shared with 7 other counties, such as Boone County, Carroll County and Jo Daviess County, and has 66 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 574 square miles of land (1,486 sq km). The largest is 61032 (Freeport) with 149 square miles, and the smallest is 61013 (Cedarville) with 0.5. The middle-sized code here covers 32.9 square miles; the middle value for all of Illinois is 31.5. These areas follow ZIP code delivery routes, so their total is not the official size of Stephenson County; a code can reach across its border.

By number of ZIP codes, Stephenson County ranks 35th among the 102 counties and county-level areas of Illinois (equal counts share a rank), with 14 of the 1,575 codes in the state list.

Writing an address in Stephenson County

The name of the county is not written in a United States address. The last line is the postal city, the letters IL and the ZIP code:

  • Cedarville, IL 61013
  • Dakota, IL 61018
  • Davis, IL 61019

Cedarville is also the name of a place with a ZIP code in 6 other states, which is why the two state letters and the code matter more than the town name.
