Where Vermilion County is

On the map, the ZIP codes of Vermilion County fall in the east of Illinois. From the northernmost code to the southernmost is about 38 miles, and from east to west about 17 miles. The two codes farthest apart are 60942 (Hoopeston) and 61810 (Allerton), about 40 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Warren County, Indiana (21 miles), Champaign County (24 miles), Fountain County, Indiana (28 miles) and Vermillion County, Indiana (29 miles).

The first three digits

The codes of Vermilion County begin with 618 (20 codes) and 609 (4 codes). The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 618 is shared with 3 other counties, Champaign County, De Witt County and Piatt County, and has 62 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 957 square miles of land (2,479 sq km). The largest is 60942 (Hoopeston) with 115 square miles, and the smallest is 60932 (East Lynn) with 0.3. The middle-sized code here covers 29.3 square miles; the middle value for all of Illinois is 31.5. These areas follow ZIP code delivery routes, so their total is not the official size of Vermilion County; a code can reach across its border.

By number of ZIP codes, Vermilion County ranks 13th among the 102 counties and county-level areas of Illinois (equal counts share a rank), with 24 of the 1,575 codes in the state list.

Writing an address in Vermilion County

The name of the county is not written in a United States address. The last line is the postal city, the letters IL and the ZIP code:

  • Danville, IL 61832 (one of 2 codes for Danville; the street decides which)
  • Allerton, IL 61810
  • Alvin, IL 61811

Danville is also the name of a place with a ZIP code in 16 other states, which is why the two state letters and the code matter more than the town name.

Questions about Vermilion County ZIP codes

What is the ZIP code for Danville, IL?

Danville has 2 ZIP codes in Vermilion County: 61832, 61834. Which one applies depends on the street address.

Do all ZIP codes in Vermilion County start with the same digits?

No. They use 2 different three-digit beginnings; the most common is 618, on 20 of the 24 codes.

Which ZIP code in Vermilion County covers the most land?

60942 (Hoopeston), at about 115 square miles in the Census Bureau's 2024 figures.
