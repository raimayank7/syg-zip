Where Madison County is

Going by the map points of its ZIP codes, Madison County is in the south-west of Illinois. From the northernmost code to the southernmost is about 22 miles, and from east to west about 28 miles. The two codes farthest apart are 62035 (Godfrey) and 62249 (Highland), about 31 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are St. Louis (city), Missouri (19 miles), St. Clair County (22 miles), Jersey County (25 miles) and St. Louis County, Missouri (27 miles).

The first three digits

The codes of Madison County begin with 620 (24 codes) and 622 (4 codes). The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 620 is shared with 9 other counties, such as Bond County, Calhoun County and Christian County, and has 78 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 709 square miles of land (1,837 sq km). The largest is 62025 (Edwardsville) with 112 square miles, and the smallest is 62046 (Hamel) with 1.1. The middle-sized code here covers 18.8 square miles; the middle value for all of Illinois is 31.5. Water adds about 26.0 square miles, roughly 4% of the mapped area. These areas follow ZIP code delivery routes, so their total is not the official size of Madison County; a code can reach across its border.

By number of ZIP codes, Madison County ranks 11th among the 102 counties and county-level areas of Illinois (equal counts share a rank), with 28 of the 1,575 codes in the state list.

Writing an address in Madison County

The name of the county is not written in a United States address. The last line is the postal city, the letters IL and the ZIP code:

  • Edwardsville, IL 62025 (one of 2 codes for Edwardsville; the street decides which)
  • Alhambra, IL 62001
  • Alton, IL 62002

Edwardsville is also the name of a place with a ZIP code in 3 other states, which is why the two state letters and the code matter more than the town name.

Questions about Madison County ZIP codes

What is the ZIP code for Edwardsville, IL?

Edwardsville has 2 ZIP codes in Madison County: 62025, 62026. Which one applies depends on the street address.

Do all ZIP codes in Madison County start with the same digits?

No. They use 2 different three-digit beginnings; the most common is 620, on 24 of the 28 codes.

Which ZIP code in Madison County covers the most land?

62025 (Edwardsville), at about 112 square miles in the Census Bureau's 2024 figures.
