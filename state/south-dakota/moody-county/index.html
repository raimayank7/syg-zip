ZIP codes in Moody County, South Dakota

Moody County, South Dakota has 4 ZIP codes in this list, from 57017 to 57065. They cover 4 places, among them Colman, Egan, Flandreau and Trent.

The ZIP code areas of Moody County add up to about 369 square miles of land (955 sq km) as the Census Bureau draws them. The largest is 57028 (Flandreau), with 201 square miles.

Using these codes

  • In an address, the ZIP code comes last, after the city and the two-letter state: Colman, SD 57017.
  • Tap a ZIP code to open it in the look-up, with a copy button for the address line.
  • A code can cross a county line, and one town can have several codes. The table shows the main place of each code.
  • "No area" means the Census Bureau draws no area for that code. Such codes are usually for post office boxes or a single building.
