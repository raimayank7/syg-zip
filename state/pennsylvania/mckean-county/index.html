Where McKean County is

On the map, the ZIP codes of McKean County fall in the north-west of Pennsylvania. From the northernmost code to the southernmost is about 21 miles, and from east to west about 34 miles. The two codes farthest apart are 16333 (Ludlow) and 16743 (Port Allegany), about 35 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Elk County (32 miles), Cattaraugus County, New York (32 miles), Cameron County (35 miles) and Potter County (35 miles).

The first three digits

The codes of McKean County begin with 167 (18 codes) and 163 (1 code). The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 167 is shared with 2 other counties, Elk County and Potter County, and has 23 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 1,064 square miles of land (2,755 sq km). The largest is 16735 (Kane) with 263 square miles, and the smallest is 16724 (Crosby) with 0.4. The middle-sized code here covers 15.3 square miles; the middle value for all of Pennsylvania is 11.9. These areas follow ZIP code delivery routes, so their total is not the official size of McKean County; a code can reach across its border.

By number of ZIP codes, McKean County ranks 45th among the 67 counties and county-level areas of Pennsylvania (equal counts share a rank), with 19 of the 2,176 codes in the state list.

Writing an address in McKean County

The name of the county is not written in a United States address. The last line is the postal city, the letters PA and the ZIP code:

  • Bradford, PA 16701
  • Crosby, PA 16724
  • Custer City, PA 16725

Bradford is also the name of a place with a ZIP code in 11 other states, which is why the two state letters and the code matter more than the town name.
