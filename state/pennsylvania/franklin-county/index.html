Where Franklin County is

Going by the map points of its ZIP codes, Franklin County is in the south of Pennsylvania. From the northernmost code to the southernmost is about 35 miles, and from east to west about 23 miles. The two codes farthest apart are 17214 (Blue Ridge Summit) and 17217 (Concord), about 36 miles from each other in a straight line. Measured between the middle points of their codes, the closest neighbours are Fulton County (21 miles), Washington County, Maryland (25 miles), Adams County (25 miles) and Huntingdon County (33 miles).

The first three digits

Every ZIP code of Franklin County starts with 172. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 172 is shared with 4 other counties, such as Bedford County, Cumberland County and Fulton County, and has 52 codes in all.

How much ground the codes cover

The Census Bureau draws an area for 28 of the 31 codes. Together they come to about 718 square miles of land (1,859 sq km). The largest is 17236 (Mercersburg) with 126 square miles, and the smallest is 17232 (Lurgan) with 0.02. The middle-sized code here covers 13.0 square miles; the middle value for all of Pennsylvania is 11.9. These areas follow ZIP code delivery routes, so their total is not the official size of Franklin County; a code can reach across its border. 3 codes have no mapped area: 17231 (Lemasters), 17256 (Shady Grove) and 17272 (Zullinger). Codes like these are normally for post office boxes or one large building.

By number of ZIP codes, Franklin County ranks 25th among the 67 counties and county-level areas of Pennsylvania (equal counts share a rank), with 31 of the 2,176 codes in the state list.

Writing an address in Franklin County

The name of the county is not written in a United States address. The last line is the postal city, the letters PA and the ZIP code:

  • Chambersburg, PA 17201 (one of 2 codes for Chambersburg; the street decides which)
  • Amberson, PA 17210
  • Blue Ridge Summit, PA 17214

Questions about Franklin County ZIP codes

What is the ZIP code for Chambersburg, PA?

Chambersburg has 2 ZIP codes in Franklin County: 17201, 17202. Which one applies depends on the street address.

Do all ZIP codes in Franklin County start with the same digits?

Yes. All 31 start with 172.

Which ZIP code in Franklin County covers the most land?

17236 (Mercersburg), at about 126 square miles in the Census Bureau's 2024 figures.
