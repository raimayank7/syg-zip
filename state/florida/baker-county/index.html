ZIP codes in Baker County, Florida

Baker County, Florida has 4 ZIP codes in this list, from 32040 to 32087. They cover 4 places, among them Glen Saint Mary, Macclenny, Olustee and Sanderson.

The ZIP code areas of Baker County add up to about 380 square miles of land (984 sq km) as the Census Bureau draws them. The largest is 32087 (Sanderson), with 159 square miles.

Using these codes

  • In an address, the ZIP code comes last, after the city and the two-letter state: Glen Saint Mary, FL 32040.
  • Tap a ZIP code to open it in the look-up, with a copy button for the address line.
  • A code can cross a county line, and one town can have several codes. The table shows the main place of each code.
  • "No area" means the Census Bureau draws no area for that code. Such codes are usually for post office boxes or a single building.
