Where Navajo County is

On the map, the ZIP codes of Navajo County fall in the north-east of Arizona. From the northernmost code to the southernmost is about 200 miles, and from east to west about 44 miles. The two codes farthest apart are 85926 (Fort Apache) and 86033 (Kayenta), about 201 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Apache County (54 miles), Coconino County (90 miles), Gila County (101 miles) and McKinley County, New Mexico (104 miles).

The first three digits

The codes of Navajo County begin with 859 (15 codes), 860 (12 codes) and 865 (2 codes). The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 859 is shared with 3 other counties, Apache County, Coconino County and Greenlee County, and has 26 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 9,182 square miles of land (23,780 sq km). The largest is 86047 (Winslow) with 1,677 square miles, and the smallest is 85942 (Woodruff) with 5.9. The middle-sized code here covers 229 square miles; the middle value for all of Arizona is 73.7. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Navajo County; a code can reach across its border.

By number of ZIP codes, Navajo County ranks 6th among the 15 counties and county-level areas of Arizona (equal counts share a rank), with 29 of the 530 codes in the state list.

Writing an address in Navajo County

The name of the county is not written in a United States address. The last line is the postal city, the letters AZ and the ZIP code:

  • Blue Gap, AZ 86520

Questions about Navajo County ZIP codes

What is the ZIP code for Show Low, AZ?

Show Low has 2 ZIP codes in Navajo County: 85901, 85902. Which one applies depends on the street address.

Do all ZIP codes in Navajo County start with the same digits?

No. They use 3 different three-digit beginnings; the most common is 859, on 15 of the 29 codes.

Which ZIP code in Navajo County covers the most land?

86047 (Winslow), at about 1,677 square miles in the Census Bureau's 2024 figures.
