Where Marion County is

The ZIP codes of Marion County are found in the east of Kansas. From the northernmost code to the southernmost is about 31 miles, and from east to west about 26 miles. The two codes farthest apart are 66840 (Burns) and 67483 (Tampa), about 34 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Chase County (27 miles), Harvey County (29 miles), McPherson County (29 miles) and Morris County (32 miles).

The first three digits

The codes of Marion County begin with 668 (6 codes), 670 (3 codes) and 674 (3 codes). The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 668 is shared with 7 other counties, such as Butler County, Chase County and Coffey County, and has 36 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 1,049 square miles of land (2,718 sq km). The largest is 66861 (Marion) with 205 square miles, and the smallest is 67053 (Goessel) with 0.4. The middle-sized code here covers 71.9 square miles; the middle value for all of Kansas is 80.7. These areas follow ZIP code delivery routes, so their total is not the official size of Marion County; a code can reach across its border.

By number of ZIP codes, Marion County ranks 8th among the 105 counties and county-level areas of Kansas (equal counts share a rank), with 12 of the 748 codes in the state list.

Writing an address in Marion County

The name of the county is not written in a United States address. The last line is the postal city, the letters KS and the ZIP code:

  • Burns, KS 66840
  • Durham, KS 67438
  • Florence, KS 66851

Burns is also the name of a place with a ZIP code in 4 other states, which is why the two state letters and the code matter more than the town name.

Do all ZIP codes in Marion County start with the same digits?
