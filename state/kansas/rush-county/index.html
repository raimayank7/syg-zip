Where Rush County is

The ZIP codes of Rush County are found in the west of Kansas. From the northernmost code to the southernmost is about 15 miles, and from east to west about 27 miles. The two codes farthest apart are 67556 (Mc Cracken) and 67565 (Otis), about 27 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Ellis County (23 miles), Pawnee County (24 miles), Barton County (30 miles) and Ness County (33 miles).

The first three digits

Every ZIP code of Rush County starts with 675. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 675 is shared with 8 other counties, such as Barton County, Edwards County and McPherson County, and has 55 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 836 square miles of land (2,165 sq km). The largest is 67556 (Mc Cracken) with 195 square miles, and the smallest is 67553 (Liebenthal) with 0.1. The middle-sized code here covers 106 square miles; the middle value for all of Kansas is 80.7. These areas follow ZIP code delivery routes, so their total is not the official size of Rush County; a code can reach across its border.

By number of ZIP codes, Rush County ranks 23rd among the 105 counties and county-level areas of Kansas (equal counts share a rank), with 8 of the 748 codes in the state list.

Writing an address in Rush County

The name of the county is not written in a United States address. The last line is the postal city, the letters KS and the ZIP code:

  • Alexander, KS 67513
  • Bison, KS 67520
  • La Crosse, KS 67548

Alexander is also the name of a place with a ZIP code in 6 other states, which is why the two state letters and the code matter more than the town name.
