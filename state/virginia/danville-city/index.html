Where Danville (city) is

The first three digits

All 3 codes here begin with the same three digits, 245. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 245 is shared with 11 other counties and county-level areas, such as Albemarle County, Amherst County and Appomattox County, and has 64 codes in all.

How much ground the codes cover

The Census Bureau draws an area for 2 of the 3 codes. Together they come to about 150 square miles of land (389 sq km). The largest is 24541 (Danville) with 75.2 square miles, and the smallest is 24540 (Danville) with 75.0. The middle-sized code here covers 75.1 square miles; the middle value for all of Virginia is 28.9. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Danville (city); a code can reach across its border. One code has no mapped area: 24543. Codes like these are normally for post office boxes or one large building.
