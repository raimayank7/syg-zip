Where Andrews County is

Going by the map points of its ZIP codes, Andrews County is in the west of Texas. Measured between the middle points of their codes, the closest neighbours are Ector County (32 miles), Gaines County (37 miles), Midland County (38 miles) and Martin County (39 miles).

The first three digits

The one code here starts with 797. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 797 is shared with 15 other counties, such as Borden County, Crane County and Dawson County, and has 60 codes in all.

How much ground the codes cover

The Census Bureau draws an area for one code here, 79714 (Andrews): 761 square miles of land. These areas follow ZIP code delivery routes, so their total is not the official size of Andrews County; a code can reach across its border.

By number of ZIP codes, Andrews County ranks 238th among the 254 counties and county-level areas of Texas (equal counts share a rank), with 1 of the 2,600 codes in the state list.

Writing an address in Andrews County

The name of the county is not written in a United States address. The last line is the postal city, the letters TX and the ZIP code:

  • Andrews, TX 79714

Andrews is also the name of a place with a ZIP code in 3 other states, which is why the two state letters and the code matter more than the town name.
