Where Ottawa County is

The ZIP codes of Ottawa County are found in the north-east of Oklahoma. From the northernmost code to the southernmost is about 24 miles, and from east to west about 13 miles. The two codes farthest apart are 74331 (Afton) and 74360 (Picher), about 25 miles from each other in a straight line. Measured between the middle points of their codes, the closest neighbours are Craig County (20 miles), Cherokee County, Kansas (20 miles), McDonald County, Missouri (29 miles) and Newton County, Missouri (30 miles).

The first three digits

Every ZIP code of Ottawa County starts with 743. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 743 is shared with 3 other counties, Craig County, Delaware County and Mayes County, and has 34 codes in all.

How much ground the codes cover

The Census Bureau draws an area for 8 of the 10 codes. Together they come to about 554 square miles of land (1,436 sq km). The largest is 74354 (Miami) with 184 square miles, and the smallest is 74358 (North Miami) with 0.1. The middle-sized code here covers 64.8 square miles; the middle value for all of Oklahoma is 77.4. Water adds about 36.3 square miles, roughly 6% of the mapped area. These areas follow ZIP code delivery routes, so their total is not the official size of Ottawa County; a code can reach across its border. 2 codes have no mapped area: 74335 (Cardin) and 74355 (Miami). Codes like these are normally for post office boxes or one large building.

By number of ZIP codes, Ottawa County ranks 18th among the 77 counties and county-level areas of Oklahoma (equal counts share a rank), with 10 of the 765 codes in the state list.

Writing an address in Ottawa County

The name of the county is not written in a United States address. The last line is the postal city, the letters OK and the ZIP code:

  • Miami, OK 74354 (one of 2 codes for Miami; the street decides which)
  • Afton, OK 74331
  • Cardin, OK 74335

Miami is also the name of a place with a ZIP code in 7 other states, which is why the two state letters and the code matter more than the town name.

Questions about Ottawa County ZIP codes

What is the ZIP code for Miami, OK?

Miami has 2 ZIP codes in Ottawa County: 74354, 74355. Which one applies depends on the street address.

Do all ZIP codes in Ottawa County start with the same digits?

Yes. All 10 start with 743.

Which ZIP code in Ottawa County covers the most land?

74354 (Miami), at about 184 square miles in the Census Bureau's 2024 figures.
