Where Texas County is

On the map, the ZIP codes of Texas County fall in the north-west of Oklahoma. From the northernmost code to the southernmost is about 30 miles, and from east to west about 43 miles. The two codes farthest apart are 73949 (Texhoma) and 73951 (Tyrone), about 52 miles from each other in a straight line. Measured between the middle points of their codes, the closest neighbours are Sherman County, Texas (36 miles), Morton County, Kansas (36 miles), Ochiltree County, Texas (36 miles) and Stevens County, Kansas (37 miles).

The first three digits

Every ZIP code of Texas County starts with 739. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 739 is shared with 3 other counties, such as Beaver County and Cimarron County, and has 16 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 2,153 square miles of land (5,575 sq km). The largest is 73942 (Guymon) with 602 square miles, and the smallest is 73901 (Adams) with 0.5. The middle-sized code here covers 403 square miles; the middle value for all of Oklahoma is 77.4. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Texas County; a code can reach across its border.

By number of ZIP codes, Texas County ranks 41st among the 77 counties and county-level areas of Oklahoma (equal counts share a rank), with 7 of the 765 codes in the state list.

Writing an address in Texas County

The name of the county is not written in a United States address. The last line is the postal city, the letters OK and the ZIP code:

  • Adams, OK 73901
  • Goodwell, OK 73939
  • Guymon, OK 73942

Adams is also the name of a place with a ZIP code in 9 other states, which is why the two state letters and the code matter more than the town name.
