Where Richland County is

On the map, the ZIP codes of Richland County fall in the south-east of North Dakota. Its codes spread over about 37 miles from north to south and 27 miles from east to west. The two codes farthest apart are 58030 (Fairmount) and 58077 (Walcott), about 41 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Wilkin County, Minnesota (19 miles), Ransom County (37 miles), Sargent County (39 miles) and Traverse County, Minnesota (39 miles).

The first three digits

Every ZIP code of Richland County starts with 580. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 580 is shared with 6 other counties, such as Barnes County, Cass County and Ransom County, and has 60 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 1,352 square miles of land (3,502 sq km). The largest is 58075 (Wahpeton) with 235 square miles, and the smallest is 58076 (Wahpeton) with 0.07. The middle-sized code here covers 70.1 square miles; the middle value for all of North Dakota is 146. Small code areas usually go with towns and suburbs where homes stand close together. These areas follow ZIP code delivery routes, so their total is not the official size of Richland County; a code can reach across its border.

By number of ZIP codes, Richland County ranks 4th among the 53 counties and county-level areas of North Dakota (equal counts share a rank), with 14 of the 407 codes in the state list.

Writing an address in Richland County

The name of the county is not written in a United States address. The last line is the postal city, the letters ND and the ZIP code:

  • Wahpeton, ND 58074 (one of 3 codes for Wahpeton; the street decides which)
  • Abercrombie, ND 58001
  • Barney, ND 58008

Questions about Richland County ZIP codes

What is the ZIP code for Wahpeton, ND?

Wahpeton has 3 ZIP codes in Richland County: 58074, 58075, 58076. Which one applies depends on the street address.

Do all ZIP codes in Richland County start with the same digits?

Yes. All 14 start with 580.

Which ZIP code in Richland County covers the most land?
