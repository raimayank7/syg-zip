Where LaMoure County is

Going by the map points of its ZIP codes, LaMoure County is in the south-east of North Dakota. From the northernmost code to the southernmost is about 17 miles, and from east to west about 41 miles. The two codes farthest apart are 58456 (Kulm) and 58490 (Verona), about 41 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Dickey County (24 miles), Logan County (41 miles), Stutsman County (41 miles) and Barnes County (42 miles).

The first three digits

All 8 codes here begin with the same three digits, 584. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 584 is shared with 11 other counties, such as Barnes County, Burleigh County and Dickey County, and has 62 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 1,380 square miles of land (3,575 sq km). The largest is 58433 (Edgeley) with 322 square miles, and the smallest is 58415 (Berlin) with 61.1. The middle-sized code here covers 176 square miles; the middle value for all of North Dakota is 146. These areas follow ZIP code delivery routes, so their total is not the official size of LaMoure County; a code can reach across its border.

By number of ZIP codes, LaMoure County ranks 18th among the 53 counties and county-level areas of North Dakota (equal counts share a rank), with 8 of the 407 codes in the state list.

Writing an address in LaMoure County

The name of the county is not written in a United States address. The last line is the postal city, the letters ND and the ZIP code:

  • Berlin, ND 58415
  • Dickey, ND 58431
  • Edgeley, ND 58433

Berlin is also the name of a place with a ZIP code in 10 other states, which is why the two state letters and the code matter more than the town name.
