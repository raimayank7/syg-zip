Where DeKalb County is

On the map, the ZIP codes of DeKalb County fall in the north-east of Indiana. From the northernmost code to the southernmost is about 18 miles, and from east to west about 13 miles. The two codes farthest apart are 46705 (Ashley) and 46788 (Spencerville), about 19 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Steuben County (16 miles), Noble County (21 miles), Allen County (21 miles) and LaGrange County (25 miles).

The first three digits

Every ZIP code of DeKalb County starts with 467. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 467 is shared with 8 other counties, such as Adams County, Allen County and Huntington County, and has 66 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 356 square miles of land (922 sq km). The largest is 46706 (Auburn) with 87.9 square miles, and the smallest is 46705 (Ashley) with 22.2. The middle-sized code here covers 31.3 square miles; the middle value for all of Indiana is 32.6. These areas follow ZIP code delivery routes, so their total is not the official size of DeKalb County; a code can reach across its border.

By number of ZIP codes, DeKalb County ranks 46th among the 92 counties and county-level areas of Indiana (equal counts share a rank), with 8 of the 968 codes in the state list.

Writing an address in DeKalb County

The name of the county is not written in a United States address. The last line is the postal city, the letters IN and the ZIP code:

  • Ashley, IN 46705
  • Auburn, IN 46706
  • Butler, IN 46721

Ashley is also the name of a place with a ZIP code in 4 other states, which is why the two state letters and the code matter more than the town name.
