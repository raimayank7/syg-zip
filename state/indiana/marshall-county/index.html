Where Marshall County is

The ZIP codes of Marshall County are found in the north of Indiana. From the northernmost code to the southernmost is about 17 miles, and from east to west about 17 miles. The two codes farthest apart are 46570 (Tippecanoe) and 46572 (Tyner), about 20 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Starke County (20 miles), Fulton County (20 miles), St. Joseph County (22 miles) and Kosciusko County (23 miles).

The first three digits

Every ZIP code of Marshall County starts with 465. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 465 is shared with 5 other counties, such as Elkhart County, Kosciusko County and LaGrange County, and has 52 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 479 square miles of land (1,242 sq km). The largest is 46563 (Plymouth) with 153 square miles, and the smallest is 46513 (Donaldson) with 0.10. The middle-sized code here covers 66.6 square miles; the middle value for all of Indiana is 32.6. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Marshall County; a code can reach across its border.

By number of ZIP codes, Marshall County ranks 36th among the 92 counties and county-level areas of Indiana (equal counts share a rank), with 9 of the 968 codes in the state list.
