Where Franklin County is

The ZIP codes of Franklin County are found in the east of Indiana. From the northernmost code to the southernmost is about 18 miles, and from east to west about 23 miles. The two codes farthest apart are 47003 (West College Corner) and 47036 (Oldenburg), about 26 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Union County (15 miles), Fayette County (18 miles), Dearborn County (21 miles) and Ripley County (24 miles).

The first three digits

Every ZIP code of Franklin County starts with 470. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 470 is shared with 4 other counties, such as Dearborn County, Ohio County and Ripley County, and has 31 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 321 square miles of land (832 sq km). The largest is 47012 (Brookville) with 166 square miles, and the smallest is 47035 (New Trenton) with 0.4. The middle-sized code here covers 18.4 square miles; the middle value for all of Indiana is 32.6. These areas follow ZIP code delivery routes, so their total is not the official size of Franklin County; a code can reach across its border.

By number of ZIP codes, Franklin County ranks 46th among the 92 counties and county-level areas of Indiana (equal counts share a rank), with 8 of the 968 codes in the state list.

Writing an address in Franklin County

The name of the county is not written in a United States address. The last line is the postal city, the letters IN and the ZIP code:

  • Bath, IN 47010
  • Brookville, IN 47012
  • Cedar Grove, IN 47016

Bath is also the name of a place with a ZIP code in 10 other states, which is why the two state letters and the code matter more than the town name.
