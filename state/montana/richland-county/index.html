Where Richland County is

The ZIP codes of Richland County are found in the north-east of Montana. From the northernmost code to the southernmost is about 26 miles, and from east to west about 20 miles. The two codes farthest apart are 59221 (Fairview) and 59262 (Savage), about 26 miles from each other in a straight line. Measured between the middle points of their codes, the closest neighbours are Dawson County (40 miles), Roosevelt County (42 miles), McKenzie County, North Dakota (47 miles) and Wibaux County (50 miles).

The first three digits

Every ZIP code of Richland County starts with 592. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 592 is shared with 7 other counties, such as Daniels County, Dawson County and McCone County, and has 41 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 1,831 square miles of land (4,743 sq km). The largest is 59270 (Sidney) with 891 square miles, and the smallest is 59217 (Crane) with 3.7. The middle-sized code here covers 305 square miles; the middle value for all of Montana is 262. These areas follow ZIP code delivery routes, so their total is not the official size of Richland County; a code can reach across its border.

By number of ZIP codes, Richland County ranks 33rd among the 56 counties and county-level areas of Montana (equal counts share a rank), with 5 of the 404 codes in the state list.

Writing an address in Richland County

The name of the county is not written in a United States address. The last line is the postal city, the letters MT and the ZIP code:

  • Crane, MT 59217
  • Fairview, MT 59221
  • Lambert, MT 59243

Crane is also the name of a place with a ZIP code in 4 other states, which is why the two state letters and the code matter more than the town name.
