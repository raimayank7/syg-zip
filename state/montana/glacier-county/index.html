Where Glacier County is

The ZIP codes of Glacier County are found in the north-west of Montana. From the northernmost code to the southernmost is about 30 miles, and from east to west about 46 miles. The two codes farthest apart are 59411 (Babb) and 59427 (Cut Bank), about 48 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Pondera County (50 miles), Toole County (56 miles), Flathead County (61 miles) and Teton County (70 miles).

The first three digits

Every ZIP code of Glacier County starts with 594. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 594 is shared with 9 other counties, such as Cascade County, Chouteau County and Fergus County, and has 64 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 3,032 square miles of land (7,854 sq km). The largest is 59427 (Cut Bank) with 1,381 square miles, and the smallest is 59411 (Babb) with 216. The middle-sized code here covers 718 square miles; the middle value for all of Montana is 262. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Glacier County; a code can reach across its border.

By number of ZIP codes, Glacier County ranks 38th among the 56 counties and county-level areas of Montana (equal counts share a rank), with 4 of the 404 codes in the state list.

Writing an address in Glacier County

The name of the county is not written in a United States address. The last line is the postal city, the letters MT and the ZIP code:
