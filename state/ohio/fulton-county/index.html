Where Fulton County is

Going by the map points of its ZIP codes, Fulton County is in the north-west of Ohio. From the northernmost code to the southernmost is about 11 miles, and from east to west about 23 miles. The two codes farthest apart are 43521 (Fayette) and 43558 (Swanton), about 24 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Henry County (19 miles), Lenawee County, Michigan (21 miles), Williams County (24 miles) and Lucas County (28 miles).

The first three digits

Every ZIP code of Fulton County starts with 435. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 435 is shared with 5 other counties, such as Defiance County, Henry County and Lucas County, and has 55 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 460 square miles of land (1,192 sq km). The largest is 43567 (Wauseon) with 114 square miles, and the smallest is 43553 (Pettisville) with 0.3. The middle-sized code here covers 69.5 square miles; the middle value for all of Ohio is 22.2. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Fulton County; a code can reach across its border.

By number of ZIP codes, Fulton County ranks 75th among the 88 counties and county-level areas of Ohio (equal counts share a rank), with 8 of the 1,416 codes in the state list.

Writing an address in Fulton County
