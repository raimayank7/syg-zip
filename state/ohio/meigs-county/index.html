Where Meigs County is

On the map, the ZIP codes of Meigs County fall in the south-east of Ohio. From the northernmost code to the southernmost is about 13 miles, and from east to west about 25 miles. The two codes farthest apart are 45741 (Langsville) and 45772 (Reedsville), about 25 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Mason County, West Virginia (18 miles), Athens County (21 miles), Jackson County, West Virginia (23 miles) and Gallia County (23 miles).

The first three digits

Every ZIP code of Meigs County starts with 457. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 457 is shared with 4 other counties, such as Athens County, Monroe County and Noble County, and has 52 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 359 square miles of land (929 sq km). The largest is 45769 (Pomeroy) with 105 square miles, and the smallest is 45720 (Chester) with 0.10. The middle-sized code here covers 31.1 square miles; the middle value for all of Ohio is 22.2. These areas follow ZIP code delivery routes, so their total is not the official size of Meigs County; a code can reach across its border.

By number of ZIP codes, Meigs County ranks 47th among the 88 counties and county-level areas of Ohio (equal counts share a rank), with 11 of the 1,416 codes in the state list.

Writing an address in Meigs County

The name of the county is not written in a United States address. The last line is the postal city, the letters OH and the ZIP code:

  • Chester, OH 45720
  • Langsville, OH 45741
  • Long Bottom, OH 45743

Chester is also the name of a place with a ZIP code in 23 other states, which is why the two state letters and the code matter more than the town name.
