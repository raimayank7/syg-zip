Where Murray County is

The ZIP codes of Murray County are found in the south-west of Minnesota. From the northernmost code to the southernmost is about 15 miles, and from east to west about 21 miles. The two codes farthest apart are 56125 (Dovray) and 56151 (Lake Wilson), about 22 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Nobles County (22 miles), Pipestone County (24 miles), Cottonwood County (28 miles) and Lyon County (31 miles).

The first three digits

Every ZIP code of Murray County starts with 561. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 561 is shared with 10 other counties, such as Cottonwood County, Jackson County and Lincoln County, and has 66 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 599 square miles of land (1,551 sq km). The largest is 56131 (Fulda) with 172 square miles, and the smallest is 56125 (Dovray) with 0.2. The middle-sized code here covers 61.9 square miles; the middle value for all of Minnesota is 62.9. These areas follow ZIP code delivery routes, so their total is not the official size of Murray County; a code can reach across its border.

By number of ZIP codes, Murray County ranks 45th among the 87 counties and county-level areas of Minnesota (equal counts share a rank), with 8 of the 992 codes in the state list.

Writing an address in Murray County

The name of the county is not written in a United States address. The last line is the postal city, the letters MN and the ZIP code:

  • Avoca, MN 56114
  • Chandler, MN 56122
  • Currie, MN 56123

Avoca is also the name of a place with a ZIP code in 8 other states, which is why the two state letters and the code matter more than the town name.
