Where Olmsted County is

The ZIP codes of Olmsted County are found in the south-east of Minnesota. From the northernmost code to the southernmost is about 20 miles, and from east to west about 24 miles. The two codes farthest apart are 55920 (Byron) and 55929 (Dover), about 24 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Dodge County (20 miles), Wabasha County (20 miles), Mower County (29 miles) and Fillmore County (30 miles).

The first three digits

Every ZIP code of Olmsted County starts with 559. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 559 is shared with 8 other counties, such as Dodge County, Fillmore County and Goodhue County, and has 73 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 513 square miles of land (1,329 sq km). The largest is 55976 (Stewartville) with 91.0 square miles, and the smallest is 55905 (Rochester) with 0.06. The middle-sized code here covers 44.0 square miles; the middle value for all of Minnesota is 62.9. These areas follow ZIP code delivery routes, so their total is not the official size of Olmsted County; a code can reach across its border.

By number of ZIP codes, Olmsted County ranks 26th among the 87 counties and county-level areas of Minnesota (equal counts share a rank), with 11 of the 992 codes in the state list.

Writing an address in Olmsted County

The name of the county is not written in a United States address. The last line is the postal city, the letters MN and the ZIP code:

  • Rochester, MN 55901 (one of 6 codes for Rochester; the street decides which)
  • Byron, MN 55920
  • Dover, MN 55929

Rochester is also the name of a place with a ZIP code in 12 other states, which is why the two state letters and the code matter more than the town name.

Questions about Olmsted County ZIP codes

What is the ZIP code for Rochester, MN?

Rochester has 6 ZIP codes in Olmsted County: 55901, 55902, 55903, 55904, 55905, 55906. Which one applies depends on the street address.

Do all ZIP codes in Olmsted County start with the same digits?

Yes. All 11 start with 559.

Which ZIP code in Olmsted County covers the most land?

55976 (Stewartville), at about 91.0 square miles in the Census Bureau's 2024 figures.
