Where Coos County is

On the map, the ZIP codes of Coos County fall in the north-east of New Hampshire. From the northernmost code to the southernmost is about 57 miles, and from east to west about 23 miles. The two codes farthest apart are 03575 (Bretton Woods) and 03592 (Pittsburg), about 57 miles from each other in a straight line. The first three digits

All 16 codes here begin with the same three digits, 035. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 035 is shared with 1 other county, Grafton County, and has 21 codes in all.

How much ground the codes cover

The middle-sized code here covers 110 square miles; the middle value for all of New Hampshire is 28.8. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Coos County; a code can reach across its border. One code has no mapped area: 03589 (Mount Washington). Codes like these are normally for post office boxes or one large building.
