Where Dare County is

The ZIP codes of Dare County are found in the north-east of North Carolina. From the northernmost code to the southernmost is about 58 miles, and from east to west about 21 miles. The two codes farthest apart are 27943 (Hatteras) and 27949 (Kitty Hawk), about 58 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Hyde County (35 miles), Tyrrell County (39 miles), Currituck County (49 miles) and Washington County (56 miles).

The first three digits

All 14 codes here begin with the same three digits, 279. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 279 is shared with 11 other counties, such as Bertie County, Camden County and Chowan County, and has 61 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 382 square miles of land (989 sq km). The largest is 27953 (Manns Harbor) with 262 square miles, and the smallest is 27982 (Waves) with 0.7. The middle-sized code here covers 8.5 square miles; the middle value for all of North Carolina is 42.4. Small code areas usually go with towns and suburbs where homes stand close together. Water adds about 137 square miles, roughly 26% of the mapped area. These areas follow ZIP code delivery routes, so their total is not the official size of Dare County; a code can reach across its border.

By number of ZIP codes, Dare County ranks 17th among the 100 counties and county-level areas of North Carolina (equal counts share a rank), with 14 of the 1,081 codes in the state list.

Writing an address in Dare County

The name of the county is not written in a United States address. The last line is the postal city, the letters NC and the ZIP code:

  • Avon, NC 27915
  • Buxton, NC 27920
  • Frisco, NC 27936

Avon is also the name of a place with a ZIP code in 11 other states, which is why the two state letters and the code matter more than the town name.
