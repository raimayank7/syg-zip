Where Concordia Parish is

On the map, the ZIP codes of Concordia Parish fall in the north of Louisiana. From the northernmost code to the southernmost is about 29 miles, and from east to west about 21 miles. The two codes farthest apart are 71316 (Acme) and 71326 (Clayton), about 34 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Adams County, Mississippi (16 miles), Catahoula Parish (20 miles), Tensas Parish (33 miles) and La Salle Parish (39 miles).

The first three digits

Every ZIP code of Concordia Parish starts with 713. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 713 is shared with 8 other parishes, such as Avoyelles Parish, Catahoula Parish and Evangeline Parish, and has 53 codes in all.

How much ground the codes cover

The Census Bureau draws an area for 5 of the 6 codes. Together they come to about 617 square miles of land (1,598 sq km). The largest is 71373 (Vidalia) with 216 square miles, and the smallest is 71316 (Acme) with 56.4. The middle-sized code here covers 138 square miles; the middle value for all of Louisiana is 45.6. Large code areas usually go with open country, where one post office serves a wide district. Water adds about 38.8 square miles, roughly 6% of the mapped area. These areas follow ZIP code delivery routes, so their total is not the official size of Concordia Parish; a code can reach across its border. One code has no mapped area: 71377 (Wildsville). Codes like these are normally for post office boxes or one large building.

By number of ZIP codes, Concordia Parish ranks 41st among the 64 parishes of Louisiana (equal counts share a rank), with 6 of the 719 codes in the state list.

Writing an address in Concordia Parish

The name of the parish is not written in a United States address. The last line is the postal city, the letters LA and the ZIP code:

  • Acme, LA 71316
  • Clayton, LA 71326
  • Ferriday, LA 71334

Acme is also the name of a place with a ZIP code in 3 other states, which is why the two state letters and the code matter more than the town name.
