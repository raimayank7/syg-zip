Where Vermilion Parish is

Going by the map points of its ZIP codes, Vermilion Parish is in the south of Louisiana. From the northernmost code to the southernmost is about 8.7 miles, and from east to west about 33 miles. The two codes farthest apart are 70528 (Delcambre) and 70542 (Gueydan), about 33 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Lafayette Parish (17 miles), Acadia Parish (23 miles), Iberia Parish (25 miles) and St. Martin Parish (27 miles).

The first three digits

Every ZIP code of Vermilion Parish starts with 705. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 705 is shared with 8 other parishes, such as Acadia Parish, Evangeline Parish and Iberia Parish, and has 75 codes in all.

How much ground the codes cover

The Census Bureau draws an area for 7 of the 8 codes. Together they come to about 1,073 square miles of land (2,779 sq km). The largest is 70548 (Kaplan) with 512 square miles, and the smallest is 70575 (Perry) with 0.03. The middle-sized code here covers 74.3 square miles; the middle value for all of Louisiana is 45.6. Water adds about 127 square miles, roughly 11% of the mapped area. These areas follow ZIP code delivery routes, so their total is not the official size of Vermilion Parish; a code can reach across its border. One code has no mapped area: 70511 (Abbeville). Codes like these are normally for post office boxes or one large building.

By number of ZIP codes, Vermilion Parish ranks 29th among the 64 parishes of Louisiana (equal counts share a rank), with 8 of the 719 codes in the state list.

Writing an address in Vermilion Parish

The name of the parish is not written in a United States address. The last line is the postal city, the letters LA and the ZIP code:

  • Abbeville, LA 70510 (one of 2 codes for Abbeville; the street decides which)
  • Delcambre, LA 70528
  • Erath, LA 70533

Abbeville is also the name of a place with a ZIP code in 4 other states, which is why the two state letters and the code matter more than the town name.
