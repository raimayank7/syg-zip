Where Washington County is

The ZIP codes of Washington County are found in the east of Nebraska. From the northernmost code to the southernmost is about 18 miles, and from east to west about 14 miles. The two codes farthest apart are 68023 (Fort Calhoun) and 68029 (Herman), about 20 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Douglas County (18 miles), Dodge County (22 miles), Harrison County, Iowa (23 miles) and Sarpy County (25 miles).

The first three digits

Every ZIP code of Washington County starts with 680. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 680 is shared with 10 other counties, such as Burt County, Butler County and Cass County, and has 57 codes in all.

How much ground the codes cover

The Census Bureau draws an area for 6 of the 7 codes. Together they come to about 348 square miles of land (902 sq km). The largest is 68008 (Blair) with 124 square miles, and the smallest is 68068 (Washington) with 0.2. The middle-sized code here covers 56.8 square miles; the middle value for all of Nebraska is 78.2. These areas follow ZIP code delivery routes, so their total is not the official size of Washington County; a code can reach across its border. One code has no mapped area: 68009 (Blair). Codes like these are normally for post office boxes or one large building.

By number of ZIP codes, Washington County ranks 28th among the 93 counties and county-level areas of Nebraska (equal counts share a rank), with 7 of the 620 codes in the state list.

Writing an address in Washington County

The name of the county is not written in a United States address. The last line is the postal city, the letters NE and the ZIP code:

  • Blair, NE 68008 (one of 2 codes for Blair; the street decides which)
  • Arlington, NE 68002
  • Fort Calhoun, NE 68023

Blair is also the name of a place with a ZIP code in 4 other states, which is why the two state letters and the code matter more than the town name.

Questions about Washington County ZIP codes

Do all ZIP codes in Washington County start with the same digits?

Yes. All 7 start with 680.

Which ZIP code in Washington County covers the most land?

68008 (Blair), at about 124 square miles in the Census Bureau's 2024 figures.
