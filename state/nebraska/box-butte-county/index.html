Where Box Butte County is

The ZIP codes of Box Butte County are found in the north-west of Nebraska. From the northernmost code to the southernmost is about 15 miles, and from east to west about 9.0 miles. The two codes farthest apart are 69301 (Alliance) and 69348 (Hemingford), about 17 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Dawes County (34 miles), Morrill County (35 miles), Sheridan County (35 miles) and Scotts Bluff County (44 miles).

The first three digits

All 2 codes here begin with the same three digits, 693. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 693 is shared with 7 other counties, such as Banner County, Dawes County and Grant County, and has 30 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 1,620 square miles of land (4,195 sq km). The largest is 69301 (Alliance) with 1,034 square miles, and the smallest is 69348 (Hemingford) with 586. The middle-sized code here covers 810 square miles; the middle value for all of Nebraska is 78.2. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Box Butte County; a code can reach across its border.

By number of ZIP codes, Box Butte County ranks 79th among the 93 counties and county-level areas of Nebraska (equal counts share a rank), with 2 of the 620 codes in the state list.
