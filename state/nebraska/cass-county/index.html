Where Cass County is

Going by the map points of its ZIP codes, Cass County is in the south-east of Nebraska. From the northernmost code to the southernmost is about 16 miles, and from east to west about 27 miles. The two codes farthest apart are 68048 (Plattsmouth) and 68347 (Eagle), about 30 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Sarpy County (18 miles), Otoe County (19 miles), Douglas County (26 miles) and Lancaster County (28 miles).

The first three digits

The codes of Cass County begin with 684 (6 codes), 683 (5 codes) and 680 (4 codes). The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 684 is shared with 14 other counties, such as Clay County, Fillmore County and Gage County, and has 56 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 582 square miles of land (1,507 sq km). The largest is 68048 (Plattsmouth) with 94.2 square miles, and the smallest is 68058 (South Bend) with 0.6. The middle-sized code here covers 42.1 square miles; the middle value for all of Nebraska is 78.2. These areas follow ZIP code delivery routes, so their total is not the official size of Cass County; a code can reach across its border.

By number of ZIP codes, Cass County ranks 3rd among the 93 counties and county-level areas of Nebraska (equal counts share a rank), with 15 of the 620 codes in the state list.

Writing an address in Cass County

The name of the county is not written in a United States address. The last line is the postal city, the letters NE and the ZIP code:

Questions about Cass County ZIP codes

Do all ZIP codes in Cass County start with the same digits?

Which ZIP code in Cass County covers the most land?
