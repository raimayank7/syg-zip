Where Cache County is

Going by the map points of its ZIP codes, Cache County is in the north of Utah. Its codes spread over about 28 miles from north to south and 12 miles from east to west. The two codes farthest apart are 84320 (Lewiston) and 84328 (Paradise), about 28 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Box Elder County (23 miles), Franklin County, Idaho (26 miles), Rich County (33 miles) and Weber County (38 miles).

The first three digits

Every ZIP code of Cache County starts with 843. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 843 is shared with 2 other counties, Box Elder County and Weber County, and has 40 codes in all.

How much ground the codes cover

The Census Bureau draws an area for 18 of the 19 codes. Together they come to about 734 square miles of land (1,902 sq km). The largest is 84321 (Logan) with 220 square miles, and the smallest is 84322 (Logan) with 0.02. The middle-sized code here covers 19.9 square miles; the middle value for all of Utah is 49.9. Small code areas usually go with towns and suburbs where homes stand close together. These areas follow ZIP code delivery routes, so their total is not the official size of Cache County; a code can reach across its border. One code has no mapped area: 84323 (Logan). Codes like these are normally for post office boxes or one large building.

By number of ZIP codes, Cache County ranks 4th among the 29 counties and county-level areas of Utah (equal counts share a rank), with 19 of the 347 codes in the state list.

Writing an address in Cache County

The name of the county is not written in a United States address. The last line is the postal city, the letters UT and the ZIP code:

  • Logan, UT 84321 (one of 4 codes for Logan; the street decides which)
  • Cache Junction, UT 84304
  • Clarkston, UT 84305

Logan is also the name of a place with a ZIP code in 7 other states, which is why the two state letters and the code matter more than the town name.

Questions about Cache County ZIP codes

What is the ZIP code for Logan, UT?

Logan has 4 ZIP codes in Cache County: 84321, 84322, 84323, 84341. Which one applies depends on the street address.

Do all ZIP codes in Cache County start with the same digits?

Yes. All 19 start with 843.

Which ZIP code in Cache County covers the most land?

84321 (Logan), at about 220 square miles in the Census Bureau's 2024 figures.
