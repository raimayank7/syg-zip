Where Box Elder County is

On the map, the ZIP codes of Box Elder County fall in the north-west of Utah. From the northernmost code to the southernmost is about 40 miles, and from east to west about 100 miles. The two codes farthest apart are 84313 (Grouse Creek) and 84324 (Mantua), about 101 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Cache County (23 miles), Oneida County, Idaho (32 miles), Franklin County, Idaho (38 miles) and Weber County (38 miles).

The first three digits

All 18 codes here begin with the same three digits, 843. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 843 is shared with 2 other counties, Cache County and Weber County, and has 40 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 3,568 square miles of land (9,241 sq km). The largest is 84313 (Grouse Creek) with 1,521 square miles, and the smallest is 84334 (Riverside) with 0.5. The middle-sized code here covers 33.7 square miles; the middle value for all of Utah is 49.9. These areas follow ZIP code delivery routes, so their total is not the official size of Box Elder County; a code can reach across its border.

By number of ZIP codes, Box Elder County ranks 5th among the 29 counties and county-level areas of Utah (equal counts share a rank), with 18 of the 347 codes in the state list.

Writing an address in Box Elder County

The name of the county is not written in a United States address. The last line is the postal city, the letters UT and the ZIP code:
