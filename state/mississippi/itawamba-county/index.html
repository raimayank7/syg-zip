Where Itawamba County is

On the map, the ZIP codes of Itawamba County fall in the north-east of Mississippi. From the northernmost code to the southernmost is about 28 miles, and from east to west about 24 miles. The two codes farthest apart are 38847 (Golden) and 38858 (Nettleton), about 37 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Lee County (19 miles), Prentiss County (22 miles), Tishomingo County (29 miles) and Monroe County (29 miles).

The first three digits

Every ZIP code of Itawamba County starts with 388. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 388 is shared with 10 other counties, such as Alcorn County, Calhoun County and Chickasaw County, and has 50 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 547 square miles of land (1,416 sq km). The largest is 38843 (Fulton) with 196 square miles, and the smallest is 38855 (Mantachie) with 61.9. The middle-sized code here covers 91.7 square miles; the middle value for all of Mississippi is 83.6. These areas follow ZIP code delivery routes, so their total is not the official size of Itawamba County; a code can reach across its border.

By number of ZIP codes, Itawamba County ranks 38th among the 82 counties and county-level areas of Mississippi (equal counts share a rank), with 5 of the 531 codes in the state list.

Writing an address in Itawamba County

The name of the county is not written in a United States address. The last line is the postal city, the letters MS and the ZIP code:

  • Fulton, MS 38843
  • Golden, MS 38847
  • Mantachie, MS 38855

Fulton is also the name of a place with a ZIP code in 14 other states, which is why the two state letters and the code matter more than the town name.
