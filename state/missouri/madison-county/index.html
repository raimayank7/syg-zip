Where Madison County is

The ZIP codes of Madison County are found in the south-east of Missouri. From the northernmost code to the southernmost is about 4.4 miles, and from east to west about 8.9 miles. The two codes farthest apart are 63645 (Fredericktown) and 63655 (Marquand), about 9.9 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Bollinger County (18 miles), Wayne County (25 miles), Iron County (29 miles) and Cape Girardeau County (31 miles).

The first three digits

All 2 codes here begin with the same three digits, 636. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 636 is shared with 7 other counties, such as Bollinger County, Iron County and Reynolds County, and has 37 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 511 square miles of land (1,324 sq km). The largest is 63645 (Fredericktown) with 359 square miles, and the smallest is 63655 (Marquand) with 152. The middle-sized code here covers 256 square miles; the middle value for all of Missouri is 51.5. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Madison County; a code can reach across its border.

By number of ZIP codes, Madison County ranks 114th among the 115 counties and county-level areas of Missouri (equal counts share a rank), with 2 of the 1,157 codes in the state list.
