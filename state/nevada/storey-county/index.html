Where Storey County is

The ZIP codes of Storey County are found in the west of Nevada. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Carson City (city) (11 miles), Lyon County (19 miles), Washoe County (20 miles) and Douglas County (23 miles).

The first three digits

The one code here starts with 894. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 894 is shared with 8 other counties, such as Churchill County, Douglas County and Humboldt County, and has 50 codes in all.

How much ground the codes cover

The Census Bureau draws an area for one code here, 89440 (Virginia City): 12.5 square miles of land. These areas follow ZIP code delivery routes, so their total is not the official size of Storey County; a code can reach across its border.

By number of ZIP codes, Storey County ranks 17th among the 17 counties and county-level areas of Nevada (equal counts share a rank), with 1 of the 254 codes in the state list.

Writing an address in Storey County

The name of the county is not written in a United States address. The last line is the postal city, the letters NV and the ZIP code:
