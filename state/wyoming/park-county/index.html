The ZIP code areas of Park County add up to about 7,262 square miles of land (18,808 sq km) as the Census Bureau draws them. The largest is 82190 (Yellowstone National Park), with 2,970 square miles.

Using these codes

  • In an address, the ZIP code comes last, after the city and the two-letter state: Yellowstone National Park, WY 82190.
  • Tap a ZIP code to open it in the look-up, with a copy button for the address line.
  • A code can cross a county line, and one town can have several codes. The table shows the main place of each code.
  • "No area" means the Census Bureau draws no area for that code. Such codes are usually for post office boxes or a single building.
