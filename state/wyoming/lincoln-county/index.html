Where Lincoln County is

The ZIP codes of Lincoln County are found in the south-west of Wyoming. Its codes spread over about 96 miles from north to south and 42 miles from east to west. The two codes farthest apart are 83124 (Opal) and 83128 (Alpine), about 103 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Bear Lake County, Idaho (33 miles), Caribou County, Idaho (44 miles), Sublette County (50 miles) and Rich County, Utah (59 miles).

The first three digits

All 16 codes here begin with the same three digits, 831. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 831 is shared with 1 other county, Sublette County, and has 18 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 2,055 square miles of land (5,321 sq km). The largest is 83101 (Kemmerer) with 530 square miles, and the smallest is 83116 (Diamondville) with 2.9. The middle-sized code here covers 51.4 square miles; the middle value for all of Wyoming is 163. Small code areas usually go with towns and suburbs where homes stand close together. These areas follow ZIP code delivery routes, so their total is not the official size of Lincoln County; a code can reach across its border.

By number of ZIP codes, Lincoln County ranks 2nd among the 23 counties and county-level areas of Wyoming (equal counts share a rank), with 16 of the 195 codes in the state list.

Writing an address in Lincoln County

The name of the county is not written in a United States address. The last line is the postal city, the letters WY and the ZIP code:

  • Afton, WY 83110
  • Alpine, WY 83128
  • Auburn, WY 83111

Afton is also the name of a place with a ZIP code in 9 other states, which is why the two state letters and the code matter more than the town name.
