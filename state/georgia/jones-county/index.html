Where Jones County is

On the map, the ZIP codes of Jones County fall close to the middle of Georgia. From the northernmost code to the southernmost is about 2.4 miles, and from east to west about 6.3 miles. The two codes farthest apart are 31032 (Gray) and 31033 (Haddock), about 6.7 miles from each other in a straight line. Measured between the middle points of their codes, the closest neighbours are Baldwin County (15 miles), Bibb County (19 miles), Putnam County (21 miles) and Jasper County (24 miles).

The first three digits

Every ZIP code of Jones County starts with 310. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 310 is shared with 26 other counties, such as Baldwin County, Bibb County and Bleckley County, and has 92 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 227 square miles of land (587 sq km). The largest is 31032 (Gray) with 159 square miles, and the smallest is 31033 (Haddock) with 67.5. The middle-sized code here covers 113 square miles; the middle value for all of Georgia is 53.5. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Jones County; a code can reach across its border.

By number of ZIP codes, Jones County ranks 125th among the 157 counties and county-level areas of Georgia (equal counts share a rank), with 2 of the 952 codes in the state list.

Writing an address in Jones County

The name of the county is not written in a United States address. The last line is the postal city, the letters GA and the ZIP code:

  • Gray, GA 31032
  • Haddock, GA 31033

Gray is also the name of a place with a ZIP code in 5 other states, which is why the two state letters and the code matter more than the town name.
