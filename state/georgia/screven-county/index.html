Where Screven County is

The ZIP codes of Screven County are found in the east of Georgia. From the northernmost code to the southernmost is about 15 miles, and from east to west about 18 miles. The two codes farthest apart are 30446 (Newington) and 30455 (Rocky Ford), about 21 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Bulloch County (17 miles), Jenkins County (22 miles), Candler County (27 miles) and Effingham County (28 miles).

The first three digits

Every ZIP code of Screven County starts with 304. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 304 is shared with 13 other counties, such as Bulloch County, Burke County and Candler County, and has 49 codes in all.

How much ground the codes cover

The Census Bureau draws an area for 4 of the 5 codes. Together they come to about 633 square miles of land (1,640 sq km). The largest is 30467 (Sylvania) with 527 square miles, and the smallest is 30449 (Oliver) with 0.3. The middle-sized code here covers 53.0 square miles; the middle value for all of Georgia is 53.5. These areas follow ZIP code delivery routes, so their total is not the official size of Screven County; a code can reach across its border. One code has no mapped area: 30424 (Dover). Codes like these are normally for post office boxes or one large building.

By number of ZIP codes, Screven County ranks 55th among the 157 counties and county-level areas of Georgia (equal counts share a rank), with 5 of the 952 codes in the state list.

Writing an address in Screven County

The name of the county is not written in a United States address. The last line is the postal city, the letters GA and the ZIP code:

  • Dover, GA 30424
  • Newington, GA 30446
  • Oliver, GA 30449

Dover is also the name of a place with a ZIP code in 17 other states, which is why the two state letters and the code matter more than the town name.
