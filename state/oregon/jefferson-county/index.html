Where Jefferson County is

Going by the map points of its ZIP codes, Jefferson County is in the north of Oregon. From the northernmost code to the southernmost is about 20 miles, and from east to west about 45 miles. The two codes farthest apart are 97711 (Ashwood) and 97730 (Camp Sherman), about 49 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Deschutes County (38 miles), Crook County (45 miles), Wasco County (45 miles) and Wheeler County (58 miles).

The first three digits

Every ZIP code of Jefferson County starts with 977. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 977 is shared with 6 other counties, such as Crook County, Deschutes County and Harney County, and has 33 codes in all.

How much ground the codes cover

The Census Bureau draws an area for every code here. Together they come to about 1,205 square miles of land (3,120 sq km). The largest is 97761 (Warm Springs) with 365 square miles, and the smallest is 97730 (Camp Sherman) with 25.8. The middle-sized code here covers 276 square miles; the middle value for all of Oregon is 70.9. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Jefferson County; a code can reach across its border.

By number of ZIP codes, Jefferson County ranks 29th among the 36 counties and county-level areas of Oregon (equal counts share a rank), with 5 of the 481 codes in the state list.

Writing an address in Jefferson County

The name of the county is not written in a United States address. The last line is the postal city, the letters OR and the ZIP code:
