Where Gilliam County is

On the map, the ZIP codes of Gilliam County fall in the north of Oregon. From the northernmost code to the southernmost is about 30 miles, and from east to west about under a mile. The two codes farthest apart are 97812 (Arlington) and 97823 (Condon), about 30 miles from each other in a straight line. The nearest neighbours on the ZIP code map, measured between the middle points of their codes, are Sherman County (25 miles), Morrow County (28 miles), Wasco County (46 miles) and Wheeler County (47 miles).

The first three digits

Every ZIP code of Gilliam County starts with 978. The first three digits of a ZIP code name the mail sorting area it belongs to. The prefix 978 is shared with 7 other counties, such as Baker County, Grant County and Morrow County, and has 54 codes in all.

How much ground the codes cover

The Census Bureau draws an area for 2 of the 3 codes. Together they come to about 1,137 square miles of land (2,946 sq km). The largest is 97823 (Condon) with 677 square miles, and the smallest is 97812 (Arlington) with 461. The middle-sized code here covers 569 square miles; the middle value for all of Oregon is 70.9. Large code areas usually go with open country, where one post office serves a wide district. These areas follow ZIP code delivery routes, so their total is not the official size of Gilliam County; a code can reach across its border. One code has no mapped area: 97861 (Mikkalo). Codes like these are normally for post office boxes or one large building.

By number of ZIP codes, Gilliam County ranks 35th among the 36 counties and county-level areas of Oregon (equal counts share a rank), with 3 of the 481 codes in the state list.

Writing an address in Gilliam County

The name of the county is not written in a United States address. The last line is the postal city, the letters OR and the ZIP code:

  • Arlington, OR 97812
  • Condon, OR 97823
  • Mikkalo, OR 97861

Arlington is also the name of a place with a ZIP code in 20 other states, which is why the two state letters and the code matter more than the town name.
