How to write a United States address

Online forms, courier labels and letters to the United States all follow the same order. Getting the last line right, city, state and ZIP code, is what matters most.

The lines, in order

  1. Name of the person or company.
  2. Street line: house or building number first, then the street name. An apartment, suite or unit number goes at the end of this line or on its own line below.
  3. City, state and ZIP code on one line: the city, a comma, the two-letter state, then the ZIP code.
  4. UNITED STATES or USA on the last line, only when sending from another country.

The pattern

Line 1NAME OF PERSON
Line 2NUMBER STREET NAME, APT NUMBER
Line 3CITY, ST 12345
Line 4UNITED STATES

Filling in a web form

  • State: choose the state or type its two letters, such as CA for California or NY for New York. Every state and its letters.
  • ZIP code: the five digits. Keep a zero at the start. If the form rejects your ZIP code, check that it matches the city and state you entered; the look-up shows which place a code belongs to.
  • Phone number: US numbers have ten digits. From abroad they are written +1 and the ten digits.

Things that often go wrong

  • Writing the house number after the street name. In the United States the number comes first.
  • Leaving out the apartment or unit number in a large building.
  • Using the name of a neighbourhood instead of the postal city. The look-up shows the city name tied to a ZIP code.
  • A ZIP code from a different state than the one selected.

Real last lines to copy the pattern from

The last line is where most mistakes happen, so here it is for the place with the most ZIP codes in each of the five largest state lists on this site. Each shows the lowest code of that city; a real address needs the code of its own street.

  • Houston, TX 77001 (Texas)
  • Sacramento, CA 94203 (California)
  • Philadelphia, PA 19019 (Pennsylvania)
  • New York, NY 10001 (New York)
  • Chicago, IL 60601 (Illinois)

Post office boxes, capitals and punctuation

When mail goes to a post office box, the box takes the place of the street line: write PO BOX and the number. The city, state and ZIP code line stays the same, though box addresses often have a ZIP code of their own, different from the streets around the post office. Capital letters, as in the pattern above, are easiest for sorting machines to read, but ordinary capitals and small letters are fine on a hand-written envelope. Do not put a comma or full stop after the state letters, and leave the ZIP code as the last thing on its line. The county is never written, and neither is a neighbourhood name unless it is the postal city itself.

Checked in November 2026. General guidance, not connected with the United States Postal Service. For an important shipment, confirm the address with the receiver.
