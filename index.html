Common questions

What is a ZIP code?

A ZIP code is the five-digit postal code used for addresses in the United States.

How do I find the ZIP code of a US city?

Type the city name in the box above, optionally with the state letters, for example "Austin TX". Large cities have many ZIP codes; open the county page to see them all.

Why is my ZIP code not found?

This site uses open data, which can miss new codes and codes used only for post office boxes or single buildings. Check the digits, then confirm with the United States Postal Service.

Is this the official USPS look-up?

No. This is an independent site that uses open data from GeoNames and the U.S. Census Bureau. For mailing, the United States Postal Service has the final word.

Data checked in November 2026. Sources: GeoNames and the U.S. Census Bureau. This site is not connected with the United States Postal Service; for mailing, confirm the address with USPS.
